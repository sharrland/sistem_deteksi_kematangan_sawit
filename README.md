# Deteksi Kematangan Buah Sawit

Aplikasi berbasis Flask untuk mendeteksi tingkat kematangan buah kelapa sawit menggunakan metode Convolutional Neural Network (CNN).

## Fitur
- Upload gambar buah sawit
- Deteksi tingkat kematangan otomatis
- Menampilkan confidence prediksi
- Tampilan website menggunakan HTML, CSS, dan JavaScript

## Teknologi
- Python
- Flask
- TensorFlow / Keras
- HTML
- CSS
- JavaScript

## Cara Menjalankan

### Install dependency

```bash
pip install -r requirements.txt
```

### Jalankan Flask

```bash
python app.py
```

### Buka Browser

```text
http://127.0.0.1:5000
```
